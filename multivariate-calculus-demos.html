LOCAL CHANGE

Gradients

One dimension: the derivative is a slope

For a scalar function y = f(x), the derivative measures output change per unit input change. In numerator layout, outputs index rows and inputs index columns—even though this is a 1 × 1 matrix.

Dxy = ∂y∂x = f′(x)

Drag across the curve. The point, value, and tangent move together.

f(x) = 0.45x² − 1.2

import torch

x = torch.tensor(1.4, requires_grad=True)
y = 0.45 * x**2 - 1.2
y.backward()

print(y.item())       # f(x)
print(x.grad.item())  # df/dx = 0.9x

COMPOSED CHANGE

Chain rules & Jacobians

Single path: multiply local rates

Let x = g(t) and y = f(x). A small change in t passes through both links. Numerator layout makes the cancellation pattern visible.

dydt = ∂y∂x dxdt

Here x = t² + 1 and y = sin(2x). Drag the point; every value travels with it.

dy / dt

Two inputs, two outputs: the Jacobian

Now 𝐱 = [x₁ x₂]ᵀ maps to two different outputs, 𝐲 = [y₁ y₂]ᵀ. In numerator layout, each output gets a row and each input gets a column.

D𝐱𝐲 = [ ∂yᵢ / ∂xⱼ ] 2×2

Move x₁. The same horizontal input change travels through both functions, but the two output points move at different speeds and can even move in opposite directions.

y₁ = x₁² − x₂   ·   y₂ = sin(1.4x₁) + 0.6x₂²

import torch

def outputs(x):
    x1, x2 = x
    y1 = x1**2 - x2
    y2 = torch.sin(1.4*x1) + 0.6*x2**2
    return torch.stack([y1, y2])

x = torch.tensor([0.8, -0.5])
J = torch.func.jacrev(outputs)(x)
print(J)  # rows: outputs, columns: inputs

CHECK YOUR INTUITION

Three things to remember.

01

Shape first

A map with two outputs and two inputs has a 2 × 2 Jacobian.

02

Rows are outputs

Numerator layout puts one output per row and one input per column: (D𝐱𝐲)ij = ∂yᵢ/∂xⱼ.

03

Read a column

One Jacobian column shows how changing a single input affects every output.
