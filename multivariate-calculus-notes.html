01

ONE INPUT

Start with the familiar

Scalars and vectors

A scalar is a single number, such as x. A vector gathers several numbers into an ordered column.

x ∈ ℝ scalar
𝐱 = [x₁, x₂, …, xₘ]ᵀ ∈ ℝᵐ vector
UNIVARIATE DIFFERENTIATION

If y = f(x), its derivative is the limiting slope

dydx = limh→0 f(x+h) − f(x)h.

For f(x) = 6x² − 3x + 2, the analytical result is f′(x) = 12x − 3. A numerical estimate replaces the limit with a small value such as h = 10⁻⁴.

SUM

(f + g)′ = f′ + g′

PRODUCT

(fg)′ = f′g + fg′

QUOTIENT

(f/g)′ = (f′g − fg′)/g²

CHAIN

(g ∘ f)′(x) = g′(f(x)) f′(x)

02

MANY INPUTS

Capture every direction

Partial derivatives

Let f: ℝᵐ → ℝ. To isolate the effect of one coordinate, change only xᵢ and hold all others fixed.

∂f∂xᵢ = limh→0 f(x₁,…,xᵢ+h,…,xₘ) − f(𝐱)h

The gradient collects all these directional sensitivities into one derivative object.

NOTATION MATTERS
NUMERATOR LAYOUT · USED HERE
∇𝐱f = [ ∂f/∂x₁   ∂f/∂x₂   …   ∂f/∂xₘ ]
1 × m row vector
DENOMINATOR LAYOUT
[ ∂f/∂x₁   ∂f/∂x₂   …   ∂f/∂xₘ ]ᵀ
m × 1 column vector

The order matters because derivatives are vectors and matrices. Pick a convention and keep every multiplication shape-consistent.

WORKED EXAMPLE

Differentiate a matrix-vector product

For f(𝐱) = A𝐱, each output is a weighted sum: fᵢ(𝐱) = Σⱼ aᵢⱼxⱼ. Differentiating output i with respect to input j returns exactly aᵢⱼ.

Therefore∂(A𝐱) / ∂𝐱 = A

If f(𝐱) = 𝐱ᵀA𝐱, then ∇𝐱f = (A + Aᵀ)𝐱. For symmetric A, this becomes 2A𝐱.

04

COMPOSED CHANGE

The multivariate chain rule

ONE PARAMETER, MANY INTERMEDIATES

Let f = f(x₁, x₂), where x₁ and x₂ depend on t.

dfdt = ∂f∂𝐱∂𝐱∂t = [ ∂f/∂x₁   ∂f/∂x₂ ] [ ∂x₁/∂t   ∂x₂/∂t ]ᵀ
= ∂f∂x₁∂x₁∂t + ∂f∂x₂∂x₂∂t

Each route from t to f contributes one product of local rates. Add the routes.

1 × 2×2 × 1=1 × 1
CLASS ACTIVITY

Let f(x₁,x₂) = x₁² + 2x₂, with x₁ = sin t and x₂ = cos t. Then

dfdt = 2x₁ cos t − 2 sin t = 2 sin t (cos t − 1).
MULTIPLE PARAMETERS

If 𝐱 depends on 𝐬 = [s,t]ᵀ, the same rule becomes matrix multiplication.

∂f∂𝐬 = ∂f∂𝐱∂𝐱∂𝐬

MANY INPUTS, MANY OUTPUTS

The Jacobian

Differentiate several functions at once

Let 𝐟(𝐱) = [f₁(𝐱), f₂(𝐱), …, fₙ(𝐱)]ᵀ ∈ ℝⁿ. In numerator layout, each row tracks one output and each column tracks one input.

J = ∇𝐱𝐟 = ∂𝐟∂𝐱,   Jij = ∂fᵢ∂xⱼ
INPUTS →x₁x₂…xₘ
f₁∂f₁/∂x₁∂f₁/∂x₂…∂f₁/∂xₘ
f₂∂f₂/∂x₁∂f₂/∂x₂…∂f₂/∂xₘ
⋮⋮⋮⋱⋮
fₙ∂fₙ/∂x₁∂fₙ/∂x₂…∂fₙ/∂xₘ
↑ OUTPUTS · n × m
PHYSICAL SIGNIFICANCE

A local change of coordinates

Near a point 𝐱, a small input displacement Δ𝐱 is carried to an output displacement by the Jacobian:

Δ𝐟 ≈ J(𝐱) Δ𝐱.

Gradients and Jacobians are not just tables of partial derivatives. They are the best local linear description of how a function transforms change—and their products are the machinery behind backpropagation.
