A derivative records how change travels. Begin with one input, extend the idea across many directions, then compose those local maps with the chain rule.

01

ONE INPUT

Start with the familiar

Scalars and vectors

A scalar is a single number, such as \(x\). A vector gathers several numbers into an ordered column.

\(x \in \mathbb{R}\)scalar
\(\mathbf{x} = [x_1,x_2,\ldots,x_m]^{\mathsf T} \in \mathbb{R}^m\)vector
UNIVARIATE DIFFERENTIATION

If \(y=f(x)\), its derivative is the limiting slope

\[\frac{\mathrm{d}y}{\mathrm{d}x}=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}.\]

For \(f(x)=6x^2-3x+2\), the analytical result is \(f'(x)=12x-3\). A numerical estimate replaces the limit with a small value such as \(h=10^{-4}\).

SUM

\((f+g)'=f'+g'\)

PRODUCT

\((fg)'=f'g+fg'\)

QUOTIENT

\(\left(\frac{f}{g}\right)'=\frac{f'g-fg'}{g^2}\)

CHAIN

\((g\circ f)'(x)=g'(f(x))f'(x)\)

02

MANY INPUTS

Capture every direction

Partial derivatives

Let \(f:\mathbb{R}^m\to\mathbb{R}\). To isolate the effect of one coordinate, change only \(x_i\) and hold all others fixed.

\[\frac{\partial f}{\partial x_i}=\lim_{h\to0}\frac{f(x_1,\ldots,x_i+h,\ldots,x_m)-f(\mathbf{x})}{h}.\]

The gradient collects all these directional sensitivities into one derivative object.

NOTATION MATTERS
NUMERATOR LAYOUT · USED HERE
\[\nabla_{\mathbf{x}}f=\begin{bmatrix}\frac{\partial f}{\partial x_1}&\frac{\partial f}{\partial x_2}&\cdots&\frac{\partial f}{\partial x_m}\end{bmatrix}\]
1 × m row vector
DENOMINATOR LAYOUT
\[\begin{bmatrix}\frac{\partial f}{\partial x_1}\\[2pt]\frac{\partial f}{\partial x_2}\\ \vdots\\ \frac{\partial f}{\partial x_m}\end{bmatrix}\]
m × 1 column vector

The order matters because derivatives are vectors and matrices. Pick a convention and keep every multiplication shape-consistent.

03

USEFUL IDENTITIES

Linear maps make the pattern visible

SCALAR
\[\frac{\partial x}{\partial x}=1\]
LINEAR FUNCTION
\[\frac{\partial(mx+c)}{\partial x}=m\]
QUADRATIC
\[\frac{\partial x^2}{\partial x}=2x\]
COORDINATE PROJECTION
\[\frac{\partial x_1}{\partial\mathbf{x}}=\begin{bmatrix}1&0&\cdots&0\end{bmatrix}\]
WORKED EXAMPLE

Differentiate a matrix-vector product

For \(\mathbf{f}(\mathbf{x})=A\mathbf{x}\), each output is a weighted sum: \(f_i(\mathbf{x})=\sum_{j=1}^{n}a_{ij}x_j\). Differentiating output \(i\) with respect to input \(j\) returns exactly \(a_{ij}\).

Therefore\(\displaystyle \frac{\partial(A\mathbf{x})}{\partial\mathbf{x}}=A\)

If \(f(\mathbf{x})=\mathbf{x}^{\mathsf T}A\mathbf{x}\), then \(\nabla_{\mathbf{x}}f=(A+A^{\mathsf T})\mathbf{x}\). For symmetric \(A\), this becomes \(2A\mathbf{x}\).

04

COMPOSED CHANGE

The multivariate chain rule

ONE PARAMETER, MANY INTERMEDIATES

Let \(f=f(x_1,x_2)\), where \(x_1\) and \(x_2\) depend on \(t\).

\[\frac{\mathrm{d}f}{\mathrm{d}t}=\frac{\partial f}{\partial\mathbf{x}}\frac{\mathrm{d}\mathbf{x}}{\mathrm{d}t}=\begin{bmatrix}\frac{\partial f}{\partial x_1}&\frac{\partial f}{\partial x_2}\end{bmatrix}\begin{bmatrix}\frac{\mathrm{d}x_1}{\mathrm{d}t}\\[2pt]\frac{\mathrm{d}x_2}{\mathrm{d}t}\end{bmatrix}\]
\[=\frac{\partial f}{\partial x_1}\frac{\mathrm{d}x_1}{\mathrm{d}t}+\frac{\partial f}{\partial x_2}\frac{\mathrm{d}x_2}{\mathrm{d}t}.\]

Each route from \(t\) to \(f\) contributes one product of local rates. Add the routes.

1 × 2×2 × 1=1 × 1
CLASS ACTIVITY

Let \(f(x_1,x_2)=x_1^2+2x_2\), with \(x_1=\sin t\) and \(x_2=\cos t\). Then

\[\frac{\mathrm{d}f}{\mathrm{d}t}=2x_1\cos t-2\sin t=2\sin t\,(\cos t-1).\]
MULTIPLE PARAMETERS

If \(\mathbf{x}\) depends on \(\mathbf{s}=[s,t]^{\mathsf T}\), the same rule becomes matrix multiplication.

\[\frac{\partial f}{\partial\mathbf{s}}=\frac{\partial f}{\partial\mathbf{x}}\frac{\partial\mathbf{x}}{\partial\mathbf{s}}\]
05

MANY INPUTS, MANY OUTPUTS

The Jacobian

Differentiate several functions at once

Let \(\mathbf{f}(\mathbf{x})=[f_1(\mathbf{x}),f_2(\mathbf{x}),\ldots,f_n(\mathbf{x})]^{\mathsf T}\in\mathbb{R}^n\). In numerator layout, each row tracks one output and each column tracks one input.

\[J=\nabla_{\mathbf{x}}\mathbf{f}=\frac{\partial\mathbf{f}}{\partial\mathbf{x}},\qquad J_{ij}=\frac{\partial f_i}{\partial x_j}.\]
\[J=\begin{bmatrix}\frac{\partial f_1}{\partial x_1}&\frac{\partial f_1}{\partial x_2}&\cdots&\frac{\partial f_1}{\partial x_m}\\[4pt]\frac{\partial f_2}{\partial x_1}&\frac{\partial f_2}{\partial x_2}&\cdots&\frac{\partial f_2}{\partial x_m}\\ \vdots&\vdots&\ddots&\vdots\\[2pt]\frac{\partial f_n}{\partial x_1}&\frac{\partial f_n}{\partial x_2}&\cdots&\frac{\partial f_n}{\partial x_m}\end{bmatrix}_{n\times m}\]
ROWS: OUTPUTS · COLUMNS: INPUTS
PHYSICAL SIGNIFICANCE

A local change of coordinates

Near a point \(\mathbf{x}\), a small input displacement \(\Delta\mathbf{x}\) is carried to an output displacement by the Jacobian:

\[\Delta\mathbf{f}\approx J(\mathbf{x})\,\Delta\mathbf{x}.\]
INPUT BASIS\(\mathbf{e}_2\) ↑\(\mathbf{e}_1\) →
\(J(\mathbf{x})\)
MAPPED DIRECTIONS\(J\mathbf{e}_2\) ↖\(J\mathbf{e}_1\) ↗
Keep the shapes visible.

Gradients and Jacobians are not just tables of partial derivatives. They are the best local linear description of how a function transforms change—and their products are the machinery behind backpropagation.
